              Backup dos dados
              
      
              O MeliNotepad guarda os dados do NEX apenas neste navegador (LocalStorage). XPT e Intervalos têm backup próprio, em cada módulo. Limpar os dados do navegador apaga os registros, e os dados não sincronizam sozinhos entre dispositivos. Exporte um backup regularmente.
