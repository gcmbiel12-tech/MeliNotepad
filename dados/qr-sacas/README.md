# QR Sacas — cópias locais

A aplicação mantém os QR Codes importados no armazenamento local do navegador deste aparelho.

Para manter uma cópia dentro do projeto:
1. Abra QR Sacas.
2. Use Exportar backup JSON.
3. Salve o arquivo baixado nesta pasta: dados/qr-sacas/.

Para restaurar em outro navegador/aparelho, selecione o arquivo JSON de backup no campo de importação. O backup completo pode ser restaurado sem selecionar uma rota.

O navegador não grava automaticamente nesta pasta: o salvamento aqui é manual para respeitar as permissões de arquivos do navegador.
